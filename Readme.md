## This is a Chat Website made using FastAPI, WebSocket and basic HTML, CSS & JavaScript

### Features

#### 1. This web site allows multiple users to send messages to each other, simulating a group chat

#### 2. Users first have to provide a username so that other users can identify them by their username

#### 3. Then they are allowed to join the group chat and send messages to all the members 

## Setup Instructions

1. Clone the repository:
   ```sh
   git clone https://github.com/piyushpawar079/Chat-Website.git
   ```

2. Navigate to the project folder:
    ```sh
    cd Chat-Website
    ```

3. Install all the modules:
    ```sh
    pip install -r requirements.txt
    ```

4. Start the development server:
    ```sh
    fastapi dev app.py
    ```
